# Hagabadet - design 

## Om mappen 
Den här mappen innehåller designarbetet för webbplatsen Hagabadet. 

## Tekniker som använts
- Figma

## Wireframes
- Mobile frame: wireframe som visar webbplatsens struktur och layout för mobil. 
- Desktop frame: wireframe som visar webbplatsens struktur och layout för dator. 

## Mockup
Mockupen visar webbplatsens visuella design med färger, bilder och innehåll. Jag valde en lugn och något mörkare stil med krämvita och bruna toner samt  bilder för att skapa en elegant och harmonisk känsla som passar hagabadets spa-koncept. 

## Bildmaterial 
Bilderna som används i webbprojektet hämtades från Unsplash. Jag valde bilder med varma toner för att skapa en avslappnade spakänsla som passade den vision jag hade för webbplatsen.
