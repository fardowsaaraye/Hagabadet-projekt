# Hagabadet

## Om webbplatsen
Hagabadet är en responsiv webbplats som jag har utvecklat för att presentera en spaanläggning och dess utbud. 

Webbplatsen består av tre sidor: Hem, Upplevelser, och Kontakt. Besökaren kan läsa om Hagabadets olika upplevelser, se bilder från anläggningen och enkelt hitta  kontaktinformation. 

Hagabadet är en etablerad spaanläggning i Göteborg som erbjuder upplevelser inom spa, avkoppling och välmående. Valet av verksamhet grundar sig i mitt personliga intresse för Hagabadet och en vilja att skapa en webbplats som på ett genomtänkt sätt presenterar verksamheten. 

Webbplatsens design har utformats med fokus på enkelhet, användarvänligthet och en tydlig struktur.

## Tekniker som har använts
- HTML: för att skapa webbplatsens innehåll och struktur.
- CSS: för design, styling, layout och responsiv anpassning. 
- Javascript: för hamburgermeny, formulärvalidering och bildspel.
- Git och Github: för dokumentation av utvecklingsprocessen och versionshantering 
- Figma: för visualisering av webbplatsens design. 
- Netlify: för publicering av webbplatsen.
